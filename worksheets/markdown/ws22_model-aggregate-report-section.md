# Worksheet 22: Model aggregate-report section

*Practice output for Chapter 22, Aggregate reports and benefit–risk evaluation.*

The model text in Section 22.6 is the completed example.

| Element | What it must contain | Your text |
|---|---|---|
| Signal title | Event and interacting drug or class named explicitly |   |
| Source and status | Source; detection and validation dates; status at finalization |   |
| Background | Mechanism, DDI and QT data, label advice at interval start |   |
| Methods | Search, SMQ or terms, deduplication, inhibitor classification, case review approach |   |
| Results: cumulative and interval | Counts with and without the interacting drug; risk factors; severity; non-adherence |   |
| Exposure context | Reporting rates with limits; co-exposure assumptions |   |
| Other sources | Trials (blinded status), studies, literature |   |
| Discussion | Consistency across sources; limitations; alternative explanations |   |
| Conclusion | Confirmed, refuted, or preliminary with planned evaluation |   |
| Downstream sections | 16.4, 16.5, 18, 19 consistent with the conclusion |   |
