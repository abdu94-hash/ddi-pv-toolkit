# Worksheet 2: Clinical-relevance assessment

*Practice output for Chapter 2, Clinical relevance and patient context.*

The worksheet below is the practice output for this chapter. Complete one column of findings for each case. Use one of four entries in the *Direction* column: **Supports**, **Against**, **Neutral**, or **Unknown**. Do not assign points.

| Dimension | Guiding questions | Findings in this case | Direction | Information needed |
|---|---|---|---|---|
| Case identifiers | Case number, report date, reporter type, object drug, precipitant drug, event |   |   |   |
| 1. Mechanistic plausibility | Which drug is the object and which the precipitant? What pathway is affected? How much of the object drug's disposition depends on it? |   |   |   |
| 2. Evidence strength | What type of evidence shows a meaningful change: DDI study, outcome study, case series, extrapolation? Is it specific to these drugs? |   |   |   |
| 3. Exposure relevance | Doses, routes, formulations, start and stop dates, duration of overlap. Were the drugs actually taken? |   |   |   |
| 4. Patient susceptibility | Age, renal and hepatic function, other interacting drugs, genotype, disease state. What is left if the pathway is blocked? |   |   |   |
| 5. Clinical consequence | Severity, reversibility, detectability. Toxicity or therapeutic failure? Does the event fit the expected pattern? |   |   |   |
| 6. Actionability | Avoidable? Alternatives? Labeling advice and whether it was followed? What follow-up would resolve uncertainty? |   |   |   |
| Competing explanations | Disease, other drugs, dose errors, other exposures |   |   |   |
| Clinical-relevance statement | Judgment · driving dimensions · key uncertainty · next action |   |   |   |
