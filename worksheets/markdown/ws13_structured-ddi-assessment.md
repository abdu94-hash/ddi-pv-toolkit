# Worksheet 13: Structured DDI assessment with explicit uncertainty

*Practice output for Chapter 13, Causality and competing explanations.*

Complete one row for each drug, one for the combination, and one each for competing and contributing explanations. Use plain judgments (*principal*, *contributory*, *possible minor*, *unlikely*, *cannot assess*) with reasons.
