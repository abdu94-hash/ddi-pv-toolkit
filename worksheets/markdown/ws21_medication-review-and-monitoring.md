# Worksheet 21: Medication review and monitoring plan

*Practice output for Chapter 21, Clinical trials and medical monitoring.*

Complete the worksheet whenever a participant takes a prohibited or restricted medicine, or a concomitant medicine changes the participant's risk.

| Element | Guiding questions | Findings and plan | Responsible and timing |
|---|---|---|---|
| Participant | Study, participant number, blinded or open, study day, last study dose |   |   |
| Medication review | Every medicine with dose and dates, including OTC and herbal; tier and mechanism |   |   |
| Overlap and expected effect | Dates of overlap; direction and size of change, with source (DDI study, PBPK, labeling) |   |   |
| Safety consequence | AEs, ECG, laboratory; seriousness; AESI criteria; causality; expectedness against RSI |   |   |
| Immediate actions | Interrupt or continue; contact with treating physician; correct risk factors |   |   |
| Monitoring | Tests, timing relative to dose, action thresholds |   |   |
| Restart or discontinuation | Criteria and earliest date, with the calculation |   |   |
| Deviation handling | Classification, root cause, corrective action, notifications |   |   |
| Program-level check | Similar exposures at this site or study-wide; protocol or training changes |   |   |
