# Worksheet 3: One-page evidence profile and source comparison

*Practice output for Chapter 3, Finding and comparing interaction evidence.*

The evidence profile records what is known, from which source, and how it applies. The source comparison records each source's classification, its basis, and whether the differences matter. Together they should fit on one page.

| Item | Content | Source, version, date |
|---|---|---|
| Question being answered | Case, signal, label review, or query; one sentence |   |
| Roles and mechanism | Object drug, precipitant, pathway, expected direction |   |
| Pharmacokinetic evidence | Study type, population, doses, size of change |   |
| Pharmacodynamic evidence | Measure, population, size of change |   |
| Clinical outcome evidence | Observational and randomized; direction; confounding |   |
| Labeling (US and EU) | Section, recommendation, revision date |   |
| Applicability | Route, formulation, dose, timing, population match |   |
| Key uncertainty | The unknown that would most change the conclusion |   |
| Bottom line | Judgment and next action |   |

| Source and type | Version or date | Classification or advice | Evidence it rests on | Effect on decision |
