# Worksheet 26: Committee briefing

*Practice output for Chapter 26, Case series and safety committee recommendation.*

The completed example is the briefing in Section 26.5.

| Section | What it must contain | Entry |
|---|---|---|
| Decision requested | The specific decision; what the committee can approve, amend, or reject |   |
| Background | Product, indication, relevant labeling, exposure |   |
| Evidence | Each source with its result and its main limitation |   |
| Series evaluation | Exposure confirmation, quality, co-factors, preventability, what it cannot show |   |
| Reconciliation | Each inconsistency and the explanations that fit it |   |
| Assessment | Plausibility, uncertainty, and what is unknown, stated separately |   |
| Options | What each addresses, evidence fit, burden |   |
| Recommendation and rationale | Actions, responsible roles, and what would change the recommendation |   |
| Dissenting views | Each in its strongest form, attributed by role |   |
| Unresolved questions | Each with the evidence or study that would answer it |   |
| Reassessment | Trigger and date |   |
