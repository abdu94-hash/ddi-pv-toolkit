# Worksheet 5: Mechanism-to-consequence assessment

*Practice output for Chapter 5, Metabolic inhibition and induction.*

Complete the rows in order. Each should be answerable from the case, from a cited source, or marked unknown.

| Step | What to record | Source | Confidence |
|---|---|---|---|
| Object and precipitant | Whose exposure changes, and which drug causes it |   |   |
| Affected pathway | Enzyme or transporter, and site: gut wall, liver, kidney |   |   |
| Share of clearance (fm) | Fraction of clearance carried by that pathway |   |   |
| Mechanism type | Reversible, time-dependent, or induction |   |   |
| Expected direction | Exposure up or down; active species up or down |   |   |
| Expected size | Measured or predicted AUC ratio, with source |   |   |
| Expected timing | When the full effect appears, and when it would end |   |   |
| Exposure in this case | Doses, dates, overlap, concentrations, adherence |   |   |
| Predicted versus observed | Toxicity or therapeutic failure, and whether the event matches |   |   |
| Alternatives | Competing explanations, and a question for each |   |   |
| Conclusion | Judgment, driving rows, key uncertainty, next action |   |   |
