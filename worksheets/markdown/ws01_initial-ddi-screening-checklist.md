# Worksheet 1: Initial DDI screening checklist

*Practice output for Chapter 1, DDI assessment in everyday safety work.*

Use the checklist when a case, literature report, or query first raises an interaction question. It decides what the case needs next; it is not a causality assessment. Record **Yes**, **No**, or **Unknown**, and the follow-up that would resolve each **Unknown**.

| Item | Screening question | Finding | Status | Follow-up |
|---|---|---|---|---|
| Case identifiers | Case number, source, reporter type, event, products |   |   |   |
| Coadministration | Both drugs taken, with overlapping exposure? Doses, dates, source |   |   |   |
| Object and precipitant | Which drug changes? Which drug causes the change? |   |   |   |
| Known or plausible mechanism | Pharmacokinetic or pharmacodynamic? Source and date |   |   |   |
| Event fits expected direction | Toxicity or therapeutic failure expected? Does the event match? |   |   |   |
| Timing fits | After precipitant start or dose increase, or after an inducer stopped? Dechallenge? |   |   |   |
| Seriousness | Seriousness criteria met? Outcome? |   |   |   |
| Susceptibility flags | Age, renal and hepatic function, dose, other interacting drugs, genotype |   |   |   |
| Obvious alternatives | Disease, other drugs, exposure errors, other causes |   |   |   |
| Preventability flag | Was the combination contraindicated or advised against, and was the advice followed? |   |   |   |
| Critical missing information | Which unknowns could change the outcome of screening? |   |   |   |
| Screening outcome | Full assessment, follow-up first, or routine processing; route to signal, trial, or aggregate review |   |   |   |
