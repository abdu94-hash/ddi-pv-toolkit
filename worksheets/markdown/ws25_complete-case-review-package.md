# Worksheet 25: Complete case-review package

*Practice output for Chapter 25, Complete DDI case workshop.*

Complete one row per component. The completed example is the set of boxes and tables in Sections 25.3 to 25.7.

| Component | What it must contain | Entry for this case |
|---|---|---|
| Case identification and validity | Case number, receipt date (Day 0), reporter, four minimum elements, initial seriousness |   |
| Follow-up log | Each request: date, recipient, questions in priority order, answers received |   |
| Exposure and event timeline | Every drug with dose and dates; source of each fact; events and tests on the same axis |   |
| Event definition | Diagnosis, documentation (ECG, laboratory), severity, outcome |   |
| Mechanism and timing | Object and precipitant; pathway; exposure calculation with assumptions; fit of onset and recovery |   |
| Susceptibility and alternatives | Patient factors, other drugs, disease; what each adds or explains |   |
| Causality by contributor | Each drug, each factor, and the combination, with for, against, judgment |   |
| Relevance profile | Six dimensions: Supports, Against, Neutral, or Unknown, with reasons |   |
| Roles and coding | E2B role for each drug with rationale; MedDRA terms with rationale |   |
| Seriousness, expectedness, reporting | Criteria met; reference document used; expectedness by term; due dates |   |
| Narrative | Reported facts in chronological order, with sources |   |
| Final medical assessment | Conclusion, evidence, uncertainty, next action |   |
