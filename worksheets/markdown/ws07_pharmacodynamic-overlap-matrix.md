# Worksheet 7: Pharmacodynamic overlap matrix

*Practice output for Chapter 7, Pharmacodynamic interactions.*

The matrix is this chapter's practice output. Screen every domain, not only the one the event suggests. In the *Judgment* column use one of four entries: **No overlap**, **Overlap only**, **Overlap with evidence of harm**, or **Unknown**, with the reason in a few words. Do not assign points. Section 7.5 contains a completed, annotated example.

| Domain | Drugs and non-drug factors with this effect | Evidence beyond overlap | Patient modifiers | Judgment and information needed |
|---|---|---|---|---|
| Case identifiers | Case number, event, all drugs with start and stop dates |   |   |   |
| Bleeding | Anticoagulant, antiplatelet, NSAID, SSRI or SNRI, other |   |   |   |
| Cardiac repolarization (QT) | QT-prolonging drugs; potassium, magnesium, heart rate |   |   |   |
| CNS and respiratory depression | Opioids, benzodiazepines, gabapentinoids, alcohol, other sedatives |   |   |   |
| Serotonin toxicity | Serotonergic drugs, recent dose changes |   |   |   |
| Potassium | Drugs raising or lowering potassium; renal function |   |   |   |
| Glucose | Drugs causing, masking, or opposing hypoglycemia |   |   |   |
| Immune function | Immunosuppressive drugs, cytopenias |   |   |   |
| Other | Blood pressure, anticholinergic burden |   |   |   |
| Pharmacokinetic component | Any concurrent exposure change (Chapters 4 to 6) |   |   |   |
| Overall statement | Judgment · driving domain · key uncertainty · next action |   |   |   |
