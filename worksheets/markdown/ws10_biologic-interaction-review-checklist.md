# Worksheet 10: Biologic interaction review checklist

*Practice output for Chapter 10, Biologics and complex therapies.*

Use this checklist when a case includes a therapeutic protein, conjugate, oligonucleotide, or cell therapy. Record **Yes**, **No**, or **Unknown** in the *Status* column.

| Item | Question | Finding in this case | Status | Action or information needed |
|---|---|---|---|---|
| Modality and mechanism | What is the product, its target, and its effect on cytokines or immune function? |   |   |   |
| Disease activity | How inflamed was the patient before and after starting? CRP or other markers with dates? |   |   |   |
| Disease-mediated effect | Narrow-margin CYP substrates in the regimen? Direction expected on start and on stop? |   |   |   |
| Timing window | Dates of first and last doses; window extending weeks after the last dose? |   |   |   |
| Concentrations | Substrate levels before and after, with sample timing? |   |   |   |
| Immunogenicity | Anti-drug antibodies or loss of response? Concomitant methotrexate or other immunomodulator changes? |   |   |   |
| Immunosuppressive burden | All immunomodulators, steroids, recent long-acting biologics? Infection signs possibly masked? |   |   |   |
| Component-specific exposure | For conjugates: payload metabolism and precipitants? |   |   |   |
| Evidence available | Clinical DDI data, related-product data, mechanism only? Labeling statement and date? |   |   |   |
| Alternatives | Adherence, product change, other precipitants, disease course, sampling? |   |   |   |
| Conclusion | Relevance, key uncertainty, next action |   |   |   |
