# Worksheet 4: Absorption assessment

*Practice output for Chapter 4, Absorption- and administration-related interactions.*

Use this worksheet for any case in which an absorption or administration interaction is suspected. Record the actual administration times, not the prescribed schedule. Use **Supports**, **Against**, **Neutral**, or **Unknown** in the *Direction* column.

| Item | Guiding questions | Findings in this case | Direction | Information needed |
|---|---|---|---|---|
| Object drug | Is its absorption vulnerable to chelation, pH, binding, motility, or formulation? Narrow exposure margin? |   |   |   |
| Precipitant and mechanism | Which product and which mechanism? Include OTC products, supplements, foods, and feeds |   |   |   |
| Administration timing | Actual clock times of each product; with food or fasting; interval between them |   |   |   |
| Dose and amount | Dose of each drug; amount of cation or acid suppression |   |   |   |
| Route and formulation | Tablet, liquid, crushed, tube; modified-release or enteric-coated |   |   |   |
| Patient factors | Transit time, gastric acidity, feeding, renal or hepatic function that offsets or amplifies |   |   |   |
| Expected consequence | Rate or extent; toxicity or failure; margin to an exposure target |   |   |   |
| Evidence of altered exposure | Drug concentrations, biomarkers, response to separation or switching |   |   |   |
| Competing explanations | Adherence, resistance, disease severity, source control, other drugs |   |   |   |
| Actionability | Was separation or an alternative feasible? Was advice given? |   |   |   |
| Assessment statement | Judgment, driving factors, key uncertainty, next action |   |   |   |
