# Worksheet 20: Signal assessment report

*Practice output for Chapter 20, Signal validation and prioritization.*

| Section | Content |
|---|---|
| 1. Signal and identifiers | Product, event, interacting drug or class, signal number, report date |
| 2. Background | Mechanism; labeling and RMP status for the interaction, the event, and the link |
| 3. Detection and validation | Date, source, method; validation outcome and the new aspect |
| 4. Data reviewed | Databases, studies, exposure data, date limits |
| 5. Results | Case counts by precipitant, outcome, risk factors, label adherence; reporting rate with caveats |
| 6. Discussion | Plausibility, coherence, alternatives, reporting biases |
| 7. Prioritization | Novelty · seriousness · plausibility · exposure · preventability · uncertainty |
| 8. Conclusion | Established · not established |
| 9. Recommendations | Action · owner · due date; regulatory communication |
| 10. Uncertainties | What would change the conclusion |
| 11. Related signals | Disposition and reopening criteria |
| 12. Sign-off | Roles; next review date |
